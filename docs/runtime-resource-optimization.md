# 运行资源回收与验收记录

日期：2026-11-11。

## 默认行为

- 车机常驻，不因游戏未启动而关闭；不改变现有帧率、GPU 选择及 Chromium 启动参数。
- YouTube、Apple Music、Bilibili、喜马拉雅、抖音、红果、网易云和本地播放器，连续闲置 30 秒后关闭页面与控制器；宿主每秒检查一次。
- 前台应用、实际播放、游戏暂停后的待恢复播放、登录窗口和未完成请求保护页面。首次加载、请求和播放启动保护有 20 秒上限，防止失败请求永久占住页面；收到实际播放报告后转为播放保护。
- 用户主动暂停/停止或选择其他播放器时取消待恢复保护；游戏暂停/最小化触发的自动暂停保留保护。
- 重新进入按需创建，保留原有 Cookie、用户数据目录、登录信息与持久化偏好/历史；清除当前媒体、队列、临时页面与请求缓存，不新增现场恢复。
- `Hide`、`Pause`、`Stop` 等被动操作不创建不存在的页面。YouTube 的前台进入沿用现有语言命令初始化；后台语言更新不拉起页面。
- 页面实例编号随重建递增；过期命令及回收后、旧实例的报告被忽略。共享浏览器进程不强制结束。
- 地图没有任何显示使用者后保温 30 秒，再停止订阅/动画，终止自定义图层请求，释放 GPU 缓冲和地图实例；返回时重建。导航业务状态不随渲染资源销毁。
- 地图清单与地点缓存各保留最近两个版本；失败加载移除，允许重试。

## 可观测性

现有 `performance` 日志每 10 秒输出一次，即使没有运行游戏也继续采样：

- WestPlay 及后代进程总数、Private Bytes、私有工作集、CPU 时间增量；进程按 PID 去重。
- 内存 API 无法查询的进程不伪装成已测量，日志附测量覆盖数量；旧系统不支持私有工作集时仍报告可获取的 Private Bytes。
- 过滤创建时间晚于子进程的错误父子关系，避免 Windows 复用已退出父进程的 PID 后将无关进程算入统计。
- 每个平台的存在状态、保护原因、闲置秒数、待处理请求数，以及地图存在状态。
- `[resources]` 记录页面创建、首次就绪耗时、实例编号与闲置回收；地图创建/释放也记录事件。

## 自动与隔离验收

覆盖 29/30 秒边界、重入取消、播放/登录/待恢复保护、加载/请求超时、播放启动期间旧暂停报告、被动指令不复活、实例编号和旧响应过滤。

前端还覆盖页面释放保留登录与偏好、清理临时现场、主动暂停取消恢复、两个地图版本的缓存、失败重试、图层请求取消与清理幂等。


结果：

- UI：75 个测试文件、419 项测试通过；TypeScript 检查与生产构建通过。
- Rust 工作区：604 项通过，40 项环境依赖测试默认跳过；其中新增的两个 WebView2 冒烟测试和内存探针另行显式运行通过。
- 真实 WebView2 隔离测试通过：关闭页面后 Cookie 保留，重开仍可读取；共享配置的兄弟页面保持可执行。
- 构建后的车机在独立 WebView2 中加载成功，根节点和 Shell 已挂载，无捕获到的脚本错误。
- 前端 lint 通过，仍有原有 React 等警告；构建保留大 chunk 提示。常规 Host Clippy 通过但存在原有警告；额外的 `-D warnings` 检查被现有 mapdata 警告阻塞，未为此扩大修改范围。

## Release 受控内存测量

**这不是旧版/新版完整应用或真实平台的 A/B 测试。** 使用同一 Release 测试进程、临时用户目录、一个保留的车机页面和四个合成页面；每个合成页面创建并写入 32 MiB 数组。比较“页面继续保留”和“宿主 30 秒逻辑到期后关闭页面”两种状态，重复三轮。宿主截止时间使用可控时间推进，回收后泵消息等待 5 秒再采样。

初始只有保留页面：7 个进程，Private Bytes 146.4 MiB，私有工作集 90.7 MiB。

| 轮次 | 保留页面 Private Bytes | 回收后 Private Bytes | 本轮减少 | 私有工作集（前 → 后） | 进程数（前 → 后） |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1 | 380.6 MiB | 168.2 MiB | 212.4 MiB | 284.9 → 109.1 MiB | 11 → 7 |
| 2 | 380.6 MiB | 172.0 MiB | 208.6 MiB | 284.3 → 111.5 MiB | 11 → 7 |
| 3 | 379.5 MiB | 172.1 MiB | 207.4 MiB | 283.7 → 111.6 MiB | 11 → 7 |

全部进程的内存查询成功。回收后没有回到初始基线，说明公共浏览器缓存/运行资源仍有保留；不将页面关闭等同于所有浏览器内存归零。三轮回收后的 Private Bytes 为 168.2、172.0、172.1 MiB，但三轮短测试不足以证明长期完全无泄漏。

本地原始日志在 `target/idle-resource-memory-probe-release.log`，按构建产物忽略，不入库。测试可重复运行，实测数值随硬件、浏览器版本及系统状态变化。
